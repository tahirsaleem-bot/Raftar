# اپنی آواز میں ریکارڈ کرنا ہو تو

ابھی فلم میں Edge کی Urdu neural آواز ہے (`ur-PK-AsadNeural`)۔ آپ چاہیں تو اپنی آواز ڈال
سکتے ہیں — **پوری، یا صرف جو lines آپ کو بہتر لگیں۔**

## طریقہ

1. نیچے دی گئی ہر line **الگ الگ** ریکارڈ کریں — فون کے voice recorder پر۔
2. ہر file کا نام اُس کے number کے مطابق رکھیں: `s0`, `s1`, `s2` … `s13`
   (`.m4a`, `.mp3`, `.wav` — جو بھی فون بنائے، چلے گا)۔
3. سب files یہاں رکھ دیں:
   `C:\Raftar\exit-interview-film\my-voice\`
4. مجھے بتا دیں۔ باقی میں کر لوں گا۔

**جو line آپ ریکارڈ نہیں کریں گے، وہ neural آواز میں ہی رہے گی** — دونوں ساتھ چل سکتی ہیں،
لیکن ایک ہی فلم میں دو آوازیں عجیب لگتی ہیں، اس لیے یا سب کریں یا کوئی بھی نہیں۔

## ریکارڈنگ کی تین باتیں

- **خاموش کمرہ۔** پنکھا اور AC بند۔ فون منہ سے ایک بالشت دور۔
- **line سے پہلے اور بعد میں ایک سیکنڈ رُکیں** — میں خود trim کر لوں گا۔
- **رفتار نارمل رکھیں۔** جلدی نہ کریں؛ ہر scene اُتنی ہی لمبی ہو جائے گی جتنی آپ کی آواز ہے۔
  آواز لمبی ہوگی تو فلم لمبی ہو جائے گی، یہ ٹھیک ہے۔

آواز کا level اور format میں خود درست کر لوں گا — آپ بس صاف بول دیں۔

## Lines

**s0** — السلام علیکم۔ میں ہوں رفتار، طاہر سلیم کا agent۔ آج آپ کو پورا طریقہ دکھاتا ہوں۔

**s1** — یہ کام اب خود شروع ہوتا ہے۔ کسی کو یاد رکھنے کی ضرورت نہیں۔

**s2** — resignation آتی ہے۔ subject میں ہو، body میں ہو، یا forward ہو۔ تینوں چلتے ہیں۔

**s3** — پندرہ منٹ میں case خود کھلتا ہے، اور آپ کو email آ جاتی ہے۔

**s4** — یہ آپ کی screen ہے۔ چار خانے۔ آپ پر، تیار، انتظار، اور بھیجے جا چکے۔

**s5** — نیا case یہاں کھلتا ہے۔ نام پہلے سے بھرا ہے۔ وقت چنیں اور Send invite دبائیں۔

**s6** — invite چار کو جاتی ہے۔ جانے والے کو، جس نے کہا، People and Culture، اور notetaker۔

**s7** — notes خود واپس آتے ہیں، اور record خود لکھا جاتا ہے۔ اُسی کے اپنے الفاظ میں۔

**s8** — لفظ ٹھیک کرنا ہو تو Edit the wording دبائیں۔ فون سے ہی بدل جائے گا۔

**s9** — record thread کے سب لوگوں کو جاتا ہے۔ سوائے اُس کے، جو جا رہا ہے۔

**s10** — پھر File and send۔ PDF Drive میں، اور reply اُسی thread پر۔

**s11** — بائیں طرف Interviews on record۔ سب ایک جگہ، PDF کے ساتھ۔

**s12** — دو فیصلے آپ کے پاس رہتے ہیں۔ ملاقات کب ہو، اور کیا بھیجا جائے۔

**s13** — بس اتنا ہی۔ ایک email سے شروع، اور filed record پر ختم۔ شکریہ۔

### اگر کوئی لفظ بدلنا ہو

text بدلنا ہو تو `script.json` میں بدل دیں۔ ایک اصول: **انگریزی الفاظ انگریزی حروف میں ہی
رکھیں** (`resignation`, `email`, `Drive`) — اردو حروف میں لکھیں گے تو neural آواز اُنہیں غلط
بولتی ہے۔ آپ کی اپنی ریکارڈنگ پر یہ اصول لاگو نہیں ہوتا۔
