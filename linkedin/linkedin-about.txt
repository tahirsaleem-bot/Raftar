I make operations and HR work run smoothly, and lately I've been doing it with AI.

I work in operations and people management in Pakistan's education sector. My days cover logistics, vendor billing, hiring and employee exits: the kind of work that keeps an organisation moving but quietly eats hours when it's done by hand.

So I started automating it. I'm not a developer by training, but I've built and deployed AI agents that now handle real, daily work:

→ A logistics agent that reads meter photos from WhatsApp, logs the kilometres in Google Sheets and calculates the month-end transport invoice using each day's fuel price. When it can't read a photo clearly, it says so instead of guessing.
→ A live dashboard that gives management a daily, monthly and invoice view of the fleet.
→ An exit interview agent that picks up the request, schedules the conversation, drafts a confidential record from the notes and files it once I approve.
→ Tools for reference checks, offer letters and HR email that save time without losing the personal touch.
